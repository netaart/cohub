# Product

## Platform

web

Android（`apps/android`）是承载 Web 应用的 WebView 宿主，设计语言与 Web 一致。

## Users

- 开发者、AI 工程师、技术团队和平台构建者。
- 熟悉 DevTool、CLI、云服务和协作工具。
- 重视信息密度、状态可见性、操作效率和一致性。
- 偏好直接、精确、可解释的界面，而不是营销化表达。

## Product Purpose

Cohub 是面向开发者和技术团队的 AI agent workspace。用户在浏览器中创建 Space，与 Agent 共创，保存 Checkpoint，并管理会话、文件、任务、Channel 和运行环境。

核心体验应像一个专业的工程控制台：高密度、低噪音、可追踪、响应迅速，让用户感到系统可靠且可控。

## Capabilities and Constraints

- 技术概念直接使用英文：Space、Agent、Sandbox、Channel、Checkpoint、Task Run。
- 移动端是核心使用场景，不是桌面端的降级版本。

## Brand Commitments

- **三个词**：硬核、精确、高效
- **Voice**：专业、直接、不啰嗦。像一个靠谱的工程搭档。
- **Emotional goal**：让用户感觉“这是专业人士用的工具”——稳定、可信、可控。
- **品牌色**：`#FF3E00`。
- **文案**：短句优先，避免营销腔、夸张词和重复说明；中文和英文 / 数字之间保留合适空格。

## Product Principles

1. **State visibility** — 运行中、失败、等待、完成、同步、加载、禁用等状态必须清晰可见且语义一致。
2. **Calm confidence** — 即使处理复杂 Agent 输出和工具调用，也要保持界面稳定、克制、可预测。
3. **Functional minimalism** — 去掉不服务核心任务的元素，但保留必要状态、上下文和可追踪信息。
4. **Mobile is core** — 小屏下也要保持清晰、顺手和可控。
