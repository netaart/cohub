Opening the local model picker refreshes that Harness in the background. `cohub runtime refresh-models <harness>` requests the same refresh. An empty Codex discovery retains known models for the same provider and configured model, with current thinking and service tier defaults.

打开本地模型选择器会在后台刷新当前 Harness，也可以使用 `cohub runtime refresh-models <harness>` 手动刷新。如果 Codex 返回空列表且提供商和配置的模型未变，保留已知模型并使用当前的思考强度和服务档位默认值。
