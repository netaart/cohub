Host bridge: `display.presenting` tells a host which display the page shows, and the `display.open` event asks the page to open one. On Android an agent's screen stays in the floating indicator inside Cohub, steps aside for the one the page has open, and tapping its live preview opens it in its Space. `display.float` opens an agent screen in that indicator.
