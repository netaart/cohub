Live agent sessions

Streaming turn patches, optimistic sends, stop, rename, and stable scroll position across pagination.

Voice input

Native PCM capture wired into Cohub ASR, for when typing is not practical.

User-scoped SQLite cache hydrates instantly, then reconciles against the server on reconnect.
